# การวิเคราะห์ความสัมพันธ์ระหว่างงบโฆษณา 3 ช่องทางกับยอดขายด้วยไพธอน

โครงงานรายวิชา Computer Programming Fundamental for Statistics (ภาควิชาคณิตศาสตร์ คณะวิทยาศาสตร์ มหาวิทยาลัยบูรพา)

**ผู้จัดทำ:** ฐิติกร จันทบุรี (68030856) และ วิชญาดา คำมั่น (68030872)

## ที่มาของข้อมูล

- ชุดข้อมูล: Advertising (200 ตลาด, 4 ตัวแปรหลัก: TV, Radio, Newspaper, Sales)
- แหล่งที่มา: (https://www.kaggle.com/datasets/tawfikelmetwally/advertising-dataset)
- วันที่ดึงข้อมูล: 7 ตุลาคม 2569
- เงื่อนไขการใช้ซ้ำ: advertising-analysis

## คำถามที่ต้องการตอบ

1. งบโฆษณาช่องทางใดสัมพันธ์กับยอดขายมากที่สุด
2. แบบจำลองถดถอยเชิงเส้นพหุคูณทำนายยอดขายในชุดทดสอบได้ดีเพียงใด
3. ความสัมพันธ์เป็นแบบเส้นตรงหรือไม่ และแบบจำลองที่ซับซ้อนขึ้นดีกว่าหรือไม่

## ผลสรุป (แบ่งข้อมูล 80/20, random_state = 42)

- TV สัมพันธ์กับยอดขายสูงที่สุด (r = 0.782) รองลงมาคือ Radio (0.576) และ Newspaper (0.228)
- Linear Regression: R² ชุดทดสอบ 0.8994 (ชุดสอน 0.8957) RMSE 1.7816 MAE 1.4608
- เพิ่มพจน์ TV × Radio: R² ชุดทดสอบ 0.9743 และพหุนามดีกรี 2: 0.9869

## วิธีรัน

1. ติดตั้งแพ็กเกจ: `pip install -r requirements.txt`
2. วางไฟล์ข้อมูลดิบไว้ที่ `data/raw/Advertising_2026-10-07.csv` (มีให้แล้ว)
3. เปิดโฟลเดอร์นี้ใน VS Code (กด Restart แล้ว Run All ในแต่ละไฟล์):
   `advertising-analysis.ipynb`

ตัวเลขและกราฟทุกอย่างในเล่มรายงานสร้างจาก `notebooks/03_analysis.ipynb`
